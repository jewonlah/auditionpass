Step 01 · 유입
비로그인 표면 (SEO 자산)
  • 랜딩 / — 콜시트 에디토리얼
  • 검색 유입 → 카테고리 랜딩 ×14
  • SNS(인스타·스레드) 프로필 링크
  • 공고 상세는 비로그인도 전부 공개
숨기지 않는다 — 콘텐츠는 열고, 쓰기 행동만 게이트
Step 02 · 회원가입
구글 OAuth 원탭
  • 구글로 계속하기(주) · 이메일(보조)
  • 이메일 더블 옵트인 제거 → 이탈 0
  • returnTo 파라미터로 진입 맥락 보존
  • 약관·개인정보 동의는 가입 화면에서 1회
지원 의도는 ?apply=1로 세션 넘어 보존
Step 03 · 온보딩 (3스텝 · 스킵 가능)
3분 만에 지원 가능 상태로
  • ① 분야 선택 — 14카테고리 다중 선택
  • ② 미니 프로필 — 이름·출생연도·성별
  • ③ 첫 추천 3~5건 + "바로 지원 가능"
스킵 시 홈 완성도 카드가 잔여 스텝 회수 · returnTo 있으면 원래 공고로 복귀
Step 04 · 앱 홈 /home
개인화 허브 (로그인 착지점)
  • 원클릭 오디션 — 최상단 상시 고정
  • 프로필 완성도 카드
  • 마감 임박 · 내 분야 신규
  • 지원 현황 요약
5탭: 홈 · 탐색 · 지원 · 커뮤니티 · MY
Step 05 · 탐색 → 상세
공고 이해 → 지원 결정
  • 검색 + 카테고리 칩 + 필터 바텀시트
  • 무한스크롤 · 뒤로가기 스크롤 보존
  • 상세: D-day·검증 배지·구조화 정보
  • 마감 공고엔 "비슷한 오디션" 3건
상세 개선안 — 화면 목업 페이지 AS-IS/TO-BE 비교 참조
Step 06 · 지원 게이트 바텀시트
이탈 0 — 그 자리에서 지원
ⓐ 비로그인 → 시트 안에서 구글 로그인 → returnTo 복귀 → 시트 자동 재오픈
ⓑ 프로필 부족 → 부족 필드만 인라인 입력 → 즉시 지원 진행
ⓒ 완비 → 프로필 요약 확인 → 지원서 발송 (R2: 컴프카드 첨부)
금지: 에러 토스트 + 강제 리다이렉트. 게이트는 반드시 현재 화면 위의 시트.
Step 07 · 지원 후
지원 탭 /applications
  • 완료 시트: "지원 내역" · "비슷한 오디션"
  • 상태칩: 발송됨 → 열람됨 → 회신
  • 세그먼트: 지원함 / 찜
  • 엠티 상태 → "다음 무대 찾기" 추천
지원자 보드 /board/[token] — CD가 메일 링크로 열람(noindex)
Step 08 · MY · 개인정보
계정·설정 허브 /my
  • 프로필 2섹션: 지원 필수 / 포트폴리오
  • 상태 배지: "지원 가능 ✓ / 컴프카드"
  • 내가 쓴 글 · 공지 · FAQ · 약관
  • 개인정보 처리방침 · 계정 삭제
로그아웃은 MY 하단에만 · 삭제는 중앙 모달 confirm
