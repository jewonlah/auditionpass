# 오디션패스 디자인 언어 v2 — 「콜 시트(Call Sheet)」 (2026-07-15)

> Phase 3 시안 제작의 단일 기준. 03 진단의 A+C 하이브리드(에디토리얼 랜딩 + 유틸리티 앱) 채택.
> 브랜드 가이드라인(인디고, "믿음직한 선배" 톤) 계승하되 AI-slop 패턴 전면 금지.

## 컨셉
영화 촬영 현장의 **콜 시트(call sheet)** — 배우가 매일 받아보는 실무 문서의 규율과 밀도.
"예쁜 스타트업 랜딩"이 아니라 "현장의 도구"라는 인상. 정보가 곧 디자인이다.

## 금지 목록 (AI-slop 18건 근거 — 절대 금지)
- 그라데이션 (배경/텍스트/버튼 전부), 컬러 글로우 섀도우
- 이모지 아이콘 (아이콘은 인라인 SVG 스트로크 아이콘만)
- 균일 rounded-xl + shadow 카드의 3열 그리드 반복
- 센터 정렬 히어로 풀세트 (배지+큰제목+부제+CTA 2개 수직 나열)
- 라운드 넘버 가짜 통계 ("10,000+ 유저"), 근거 없는 사회적 증거
- 보라→핑크 계열 조합

## 타이포그래피
- 본문: **Pretendard Variable** (self-host, CDN @import 금지)
- 유틸리티 라벨: `ui-monospace` 스택 — 콜시트의 "SCENE/TAKE" 같은 대문자 모노 라벨 (11~12px, letter-spacing 0.08em, ink-40)
- 숫자: `font-variant-numeric: tabular-nums` (D-day, 카운트)
- 랜딩 스케일: 히어로 `clamp(40px, 7vw, 76px)` weight 800, letter-spacing -0.03em / 섹션 타이틀 clamp(28px, 4vw, 44px) / 본문 17px/1.7
- 앱 스케일: 화면 타이틀 iOS large-title 스타일 28~34px(700, letter-spacing -0.02em) / 리스트 타이틀 16~17px(600) / 본문 15~17px / 메타 13px / 라벨 11px 모노. 웹식 "작은 14px 본문 + 넉넉한 line-height" 금지, 링크 밑줄·파란 링크색 금지

## 레이아웃·형태
- 랜딩: 12컬럼 에디토리얼 그리드, 좌우 비대칭 허용, **헤어라인(1px line) 구획**이 기본 — 카드 박스 최소화. 세로 컨테이너 가이드라인(container-lines) 사용 가능.
- 앱: 리스트 중심 (카드 반복 대신 row + divider), 화면당 1개 주요 CTA
- **앱 = 네이티브 감각 필수 (2026-07-15 사용자 피드백 — "웹사이트 같다" 금지)**: 푸터·브레드크럼·호버 의존 인터랙션·가운데 정렬 히어로·마케팅성 헤딩 전면 금지. 상단 고정 네브바(large-title 또는 중앙 타이틀, 뒤로가기는 텍스트 없는 chevron), 터치 타깃 44px+, 리스트 row는 좌 콘텐츠/우 chevron·메타 + 인셋 divider, 바텀시트 grabber 핸들(36×5px), 풀폭 라운드 버튼(12~14px), 세그먼티드 컨트롤, 가로 스냅 캐러셀, 스크롤 시 네브바 hairline+blur, hover 대신 :active 프레스만. "모바일 웹페이지"가 아니라 iOS 네이티브 유틸리티 앱 스크린샷처럼 보일 것
- **홈(/home) 최상단 = 원클릭 오디션 섹션 상시 고정** (핵심 기능 — 2026-07-15 사용자 지시)
- radius: 컨트롤 8px / 시트·모달 상단 20px / 배지 pill. rounded-2xl 이상 남용 금지
- 섀도우: 레이어드 뉴트럴만 — `0 1px 2px rgba(20,20,20,.04), 0 8px 24px rgba(20,20,20,.08)`. 컬러 섀도우 금지
- 배지: 브랜드 가이드 준수 — 원클릭(success/white), 사이트지원(gray/white), 장르(gray100/gray700), D-day는 텍스트+tabular

## 모션 시스템 (앱형 마이크로 인터랙션)
- 토큰: fast 150ms / base 250ms / slow 400ms, easing `cubic-bezier(0.22, 1, 0.36, 1)` (ease-out-quart계)
- 바텀시트: transform 기반 스프링 느낌 `cubic-bezier(0.32, 0.72, 0, 1)` 400ms, 딤 페이드 250ms
- 리스트 스태거: 아이템당 30~40ms 딜레이, translateY(12px)+opacity, IntersectionObserver 트리거
- 탭 전환: 콘텐츠 fade+slide 8px 200ms, 탭 인디케이터 이동 250ms
- 랜딩 스크롤 리빌: 섹션당 1회, 과하지 않게 (헤드라인 워드 스태거는 히어로만)
- 프레스 피드백: scale(0.98) 100ms
- **`prefers-reduced-motion: reduce` 시 전부 무효화 필수**
- 스피너 금지 → 스켈레톤 (배경 shimmer 1.2s)

## 톤앤보이스 (카피)
- "친근하지만 믿음직한 선배" — 반말 금지, 과장 금지, 느낌표 남발 금지
- 기능이 아니라 열망: "한 곳에서 모아보세요" ❌ → "당신의 다음 무대" 계열 ⭕

- CTA 다양화: "무료로 시작하기" 반복 금지 → 맥락별 ("오늘의 공고 보기", "3분 만에 프로필 만들기")
