## 2. 프로필·폼 확정

- 계층 명칭 변경(“기본 스펙” 폐기): **`가입 필수 / 원클릭 필수 / 공고 요구 시 / 분야별 선택`**.
- **원클릭(발송) 필수 6필드**: 이름·출생연도·성별·연락처·**분야**·**얼굴 사진 1장**. "사진 없이 계속"은 원문이 사진을 요구하지 않는 공고에서만 + 강한 경고. 첫 세션 목표는 "무조건 발송"이 아니라 **"부끄럽지 않은 지원서의 미리보기 완성"**.
- 공고별 요구 필드 감지(사진/키/영상/지역/나이) → 미충족 시 발송 차단 또는 인라인 입력. 지정 양식 공고는 R1에서 자유 입력 1칸 + 미준수 발송 경고.
- R1 프로필은 6필드 + 선택(사진 추가·영상 링크)까지만. 확장 계층 전체 UI는 R2.
- 프로필 공개 링크: **기본 비공개**, 발송용 만료 토큰 링크만. 미성년 프로필은 공개 링크 금지. 카톡 아이디는 기본 수집 제외.
- 탈퇴 화면 고지: 이미 발송된 메일·수신자 보관본은 회수 불가. 사진 업로드 시 권리 보유 확인 체크.

## 3. 전환 퍼널 확정

- 배지 이원화: `이메일 지원 가능` / `외부 지원` ("지원 가능해요" 과장 금지, "검증됨" 표현 금지).
- **북극성 = 지원 의도 캡처율**: 공고 상세 방문자 중 {저장|미리보기|복사|발송} 완료 비율. 목표: 전체 5~10%, 이메일 공고 15~25%. 첫 세션 실제 발송률 기대치: 이메일 공고 방문 기준 2~5%.
- 계측 6단계: 지원 바 터치 → 로그인 완료 → 필수 필드 완료 → 사진 업로드 → 미리보기 도달 → 발송.
- 온보딩 별도 스텝 최소화 — 분야는 지원 시트 안에서, 완료 시트는 "다음 1개 행동"만.

## 4. 안전 (R1 필수)

- **미성년 감지 v0**: 카테고리(키즈·아역·연습생 등)+연령·학교·보호자·역할 표현 합산. 감지 시 **원클릭 기본 차단** → 운영자 검수 → (만 19세 미만) 보호자 연락처·확인 체크 후 해제. 만 14세 미만은 보호자 계정만(완전판은 R2, R1은 원클릭 차단으로 방어). 연령 허위 입력 시 계정 제한 고지.
- **위험 키워드 자동 조치**: 성인/노출·유흥/착취·선입금/교육비·과장 보상(고수익·데뷔 보장)·위험 채널(텔레그램 등)·신원/금융 요구·합숙/심야/1:1 — 감지 시 자동 비활성 또는 원클릭 차단. 미성년 감지와 조합 시 즉시 비활성.
- **신뢰 배지 3단계**: `검수 완료`(운영자 확인, "안전 보장 아님" 고지 필수) / `출처 확인`(trusted+7일+무신고) / `주의 필요`(신규·신고·연락처 불명·원클릭 차단).
- **신고**: 사유 10종, 사유별 자동 조치(심각 4종=즉시 원클릭 차단+강등, 비신뢰 출처면 비활성). SLA: 심각 24h / 일반 3일 / 삭제 요청 48h. 유저에겐 접수됨/조치됨/유지됨 3상태만. **심각 신고로 비활성화 시 기존 지원자에게 주의 알림 발송.**
- **운영자 어드민**(신고·검수 큐·상태 변경·소스 차단) 없이는 출시 금지.

## 5. 크롤링·이메일 법적 방어선

- **카페 글 150자 요약문 폐기** → 사실 필드화: 제목·분야·마감·접수 방식·출처 링크만 게재(콜시트형 상세 스펙 표가 그 구현체). 인용 요건 방어가 약하다는 지적 수용.
- **이메일 주소 사이트 비노출** — 상세엔 "이메일 지원 가능"만, 실주소는 발송 미리보기에서만. 자동 추출 이메일은 4조건(접수용 명시+출처 허용+무단수집 금지 표시 없음+검수 통과) 통과 시에만 원클릭 사용, 1회성 사용 원칙 명시(정보통신망법 §50조의2 대응).
- **소스 중단 기준**: 삭제 요청 1회=URL 즉시 제거(반복 시 소스 중단) / 크롤링 금지 신호(robots·403·차단·공지)=중단 / 회원 전용·로그인 벽=수집 제외 / 이메일 무단수집 금지 표시=추출 중단 / 30일 내 유효 신고 3건·삭제 2건·반송 20%·사기 2건=강등.
- **suppression 4단위**: 공고/이메일/도메인/소스. 공용 메일 도메인(gmail·naver)은 도메인 차단 금지. R1 필수.
- 마감 판정: KST 서버 기준, 날짜만 있으면 23:59:59, 불명확 마감은 경고+원문 확인.
- 발송·동의 로그(미리보기 원문·제공 항목·수신자·계정/IP·결과) 보존 — 분쟁 방어의 기초.
