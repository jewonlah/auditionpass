## 1. 서비스 정의·비전

### 1.1 한 줄 정의

> **오디션패스 — 당신의 다음 무대를 찾아주는 곳.**
> 흩어진 오디션을 한곳에 모으고, 검증하고, 에이전시급 서류로 지원하게 하는 배우·모델 커리어 플랫폼.

v1.0의 정의("원클릭 오디션 지원 플랫폼")는 기능 서술이었다. 원클릭 지원은 쇼스타·유디션이 동일하게 소구하는 방어 불가 기능이며(01 §1, §5-7), v2.0은 **기능이 아니라 결과(다음 무대)를 약속**한다. 톤은 "먼저 이 길을 걸어본 선배"의 목소리를 유지한다(D1).

### 1.2 비전 문장

- **유저에게**: "오디션 정보를 찾아 10개 사이트를 헤매고, 매번 같은 서류를 다시 만드는 시간을 없앤다. 지망생의 에너지는 준비와 연기에만 쓰이게 한다."
- **시장에게**: 사기 공고가 만연한 시장(아역 사기 5억 피해 — 01 §2 경향신문, 필름메이커스 사기 사례)에서 "검증된 공고만 모이는 곳"이라는 신뢰 표준을 만든다.
- **3년 그림**: 공급(지망생) → 수요(CD)로 확장해, 컴프카드·지원 이력이 축적된 **한국 배우·모델 커리어 그래프**가 되는 것. (Backstage의 Talent Database 모델 — 01 §3)

### 1.3 타겟 페르소나

리서치 근거: 매년 연극영화과 졸업생만 약 1,500명+ 유입(01 §1), 오디션 정보는 필름메이커스·캐스팅114·플레이DB·인스타 DM 등 10곳 이상에 분산(01 §1).

|---|---|---|---|

## 2. 문제 정의와 가치 제안

### 2.1 문제 정의 (검증된 페인포인트)

1. **분산**: 오디션 정보가 10곳 이상에 흩어져 있고, 경쟁사 대부분은 자사 등록 공고만 노출한다(01 §1). 탐색이 곧 노동이다.
2. **불신**: 유사연애·노출 요구·선입금 유도 등 사기 수법이 업계에 만연하다(01 §5-3). 지망생·부모는 공고의 진위를 스스로 판별해야 한다.
3. **전달물 품질**: 지망생의 지원 메일은 형식·구성이 제각각이라 CD에게 프로답지 않게 도달한다. 업계 표준(8x10 헤드샷+이력 컴프카드 — 01 §3)과 격차가 크다.
4. **추적 부재**: 어디에 언제 지원했는지, 읽혔는지 알 수 없다.

### 2.3 가치 사다리 (기획 레벨 복잡성 해소 — 01 §5-5)

v1.0은 가치 경험 전 요구사항이 3겹(가입→인증→프로필 필수)이었다. v2.0의 순서:

```
비로그인 열람(무료, 무조건) → 알림 구독(저마찰 훅) → 가입(구글 OAuth 우선)
→ 미니 온보딩 3스텝(스킵 가능) → 지원 시점 인라인 바텀시트로 부족분만 보완 → 지원
```

## 6. 성공 지표 (KPI)

### 6.1 노스스타 지표

> **주간 지원 완료 건수 / 활성 유저 (Weekly Applications Sent per Active User)**

이유: 지원은 유저 가치(기회 획득)·플랫폼 가치(CD 유입 통로)·수익 가치(성공 확률 과금의 전제)가 만나는 단일 행동. D2에서 지원을 무료 개방했으므로 이 지표는 과금 마찰 없이 순수하게 제품 가치를 반영한다.

### 6.2 지표 트리

```
노스스타: 주간 지원 완료 건수 / 활성 유저
├─ 획득: 주간 신규 방문 (SEO 유입 비중)
│   └─ D7 수정 효과: Google Jobs 노출 공고 수, 카테고리 랜딩 유입

│   ├─ 방문→가입 전환율 (구글 OAuth 도입 효과 측정)
│   ├─ 온보딩 완주율 (3스텝, 스킵 포함)
│   └─ 가입 후 72시간 내 첫 지원 도달률 ★ (v1: 최대 15단계 여정의 개선 검증 — 02 §3-A)
├─ 리텐션: 주간 재방문율, 알림 구독자 수, 찜 사용률
├─ 공급 품질: apply_email 보유율, 검증 공고 비율 (§5.4)
├─ 수요 씨앗: 지원자 보드 CD 클릭률, 보드→"공고 등록 문의" 전환
```

## 7. 단계별 로드맵

### Phase R1 — UX/디자인 리뉴얼 + 버그 수정 (리뉴얼 릴리즈)

- **목표**: "복잡하다" 체감의 구조적 원인 제거. 여정 단절 0.
- **범위**:
  - returnTo 전면 도입 + 즉시 수정 7건(프로필 저장 추방, 필터 초기화 버그, 로고 href, 데드엔드 CTA 숨김 등 — 02 §6.3)
  - 5탭 IA 전환, 앱 홈 신설, 로그인 시 `/`=홈
  - 구글 OAuth, 온보딩 3스텝, 프로필 게이트 바텀시트화, 폼 2단 분할
  - 디자인 A+C 하이브리드 적용, 토큰·컴포넌트 통일, 스켈레톤 로딩, 모션(reduced-motion 대응), 폰트 self-host
  - **지원 횟수 제한 폐지**(D2 — 코드 제거만으로 즉효)
  - 검증 배지 1단계(공식 소스 화이트리스트 기반)
  - 북마크(찜) + 마감 공고 "비슷한 오디션" 추천·지원 완료 후 다음 행동 제안(데드엔드 제거)
  - SEO: 사이트맵 동결 버그 수정(최우선), 상세 SSR, 메타 보강, `maximumScale:1` 제거(D7)
- **성공 기준**: 가입→첫 지원 단계 수 15 → 7 이하 / 첫 지원 도달률 기준선 2배 / 여정 중 랜딩 추방 0건 / 사이트맵 갱신 정상화.

### Phase R2 — 컴프카드 + 지원자 보드 (차별화 릴리즈)

- **목표**: 3축 차별화의 실체(전달물 품질·신뢰·수요 통로) 출시.
- **범위**:
  - 컴프카드 PDF 자동 생성 + 지원 메일 첨부(기본 템플릿)
  - 지원자 보드 웹뷰(읽기 전용) + 메일 내 링크 + "CD 계정 만들기(무료)" CTA
  - 오디션 레이더(이메일 다이제스트부터), 스텁이던 알림 설정 실구현
  - 사기 키워드 자동 플래그 + 신고 버튼(검증 2단계)
  - 크롤러: 플레이DB·기획사 공식 추가, 페이·지역 필드 구조화 + 페이 필터
  - 인스타 제보 채널 오픈
- **성공 기준**: 컴프카드 첨부 지원 비율 80%+ / 보드 CD 클릭률 10% / apply_email 보유율 +10%p / 알림 구독자 확보로 주간 재방문율 30%.

### Phase R3 — 수익화 검증 (검증 릴리즈)

- **목표**: 결제 실연동(D8 범위 밖) 없이 지불의사 실증.
- **범위**:
  - Pass Pro 사전 신청 퍼널(§4.4) + 기능별 선호 조사
  - 프리미엄 템플릿·즉시 알림·열람 확인 프로토타입(사전 신청자 한정 베타)
  - 얼리버드 연간권 한정 판매(수동 결제)
  - 지원자 보드에서 CD "공고 등록 문의" 수집 → 수요 측 리드 파이프라인
- **성공 기준**: 사전 신청 전환 5% / 실결제 10건+ / 기능별 지불의사 순위 확정 → 정식 플랜·토스 연동 사업 결정 근거 확보.

### 범위 밖 상시 원칙 (D8)

토스 결제 실연동, 카카오/네이버 로그인(사업자등록 후), CD 측 풀 대시보드, 네이티브 앱 빌드는 이번 리뉴얼에서 다루지 않는다. R3 결과가 이들의 착수 여부를 결정한다.
