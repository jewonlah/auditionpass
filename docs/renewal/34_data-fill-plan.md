## 2. 리서치에서 본 2026 수요 신호

- **숏폼 드라마 캐스팅 급증** — 필메코에 "숏폼 드라마 조연 40·50·60대 모집" 류 공고 다수, 틱톡에 "숏폼드라마 배우순위 2026" 콘텐츠. 중장년 배우 수요가 동반 상승 → 키워드 `숏폼 드라마`, `세로 드라마`, `중년 배우`, `시니어 배우`.
- **기획사 상시 오디션 상설화** — SM 상시 온라인(이메일) 오디션, 스타쉽 2026 글로벌 오디션(전국 순회, 구글폼), JYP 퍼블리싱, WAKEONE, 카카오엔터 오디션 페이지, INNIT 신인배우 오디션(1999~2010년생). → **기획사 공식 페이지 화이트리스트**(D4 지정 소스)로 1차 출처·검증 배지 재료.
- **공모전형 오디션** — 콘테스트코리아 "뷰티·선발·배우·오디션" 카테고리(대외활동 포함). 마감일·주최가 구조화돼 있어 품질 점수 높음.
- **엔터 채용(정규·계약)** — 사람인 MC(1322)·쇼호스트(1290) 카테고리, 미디어잡, 인디드 "쇼호스트 모집". 고용24 API로 공식 수집 가능(연락처 원문).

- 검색 트렌드 정량치는 네이버 데이터랩에서 직접 뽑아야 함(검색 결과 없음) — §5 측정 계획.

## 4. 실행 순서 제안 (비용 0 · 키 불필요 먼저)

1. **필메코·캐스트링크 로컬 복구 확인** → 1차 출처 비중·이메일 보유율 변화 측정 (오늘)
2. **네이버 웹문서·블로그 소싱** — 키 있음. 웹문서로 발굴한 도메인은 "화이트리스트 후보" 큐에 쌓고 운영자 승인 후 정식 소스로 승격 (이번 주)
3. **기획사 공식 페이지 + 플레이DB + 콘테스트코리아** — 규칙 기반 추출기(BaseScraper 상속, 셀렉터 최소) (이번 주)
4. 카페 키워드 2차 확장(§3) — 수율 학습 2~3회 돈 뒤 강등 결과 보고 추가 (다음 주)
5. 고용24·카카오·유튜브 — 키 발급(P1) 후 각 2시간
6. 프론트 연계(Phase 3): `quality_score` 정렬, external 후순위, 출처 배지, 카테고리 SEO 랜딩 14개

## 5. 측정 — 무엇이 "쓸 정보"인지 데이터로 결정

- `crawl_logs.details`: 키워드·카페별 수신/통과 → 통과율 <15%(표본 ≥150) 자동 강등, 주 1회 강등 목록 보고.
- `quality_score` 분포를 소스별로 주간 집계 → 평균 <0.3 소스는 "링크 인덱스"로 강등(홈 노출 제외).
- 원클릭 전환 지표(D4 apply_email 보유율)를 소스별로 — 카페는 커버리지 KPI, 사이트·고용24·메일은 원클릭 KPI로 **분리 평가**.
- 네이버 데이터랩 월 1회 수동 조회: `오디션`, `보조출연`, `쇼호스트 모집`, `아역배우`, `숏폼 드라마` 상대 검색량 → 키워드 우선순위 보정.
