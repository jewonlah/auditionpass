## 0. 이 시스템이 지키려는 것

**타깃은 아티스트다.** 배우·모델 지망생은 매일 포트폴리오와 비주얼을 보는 사람들이다.
촌스러운 화면은 그 자체로 "여기 아마추어네"라는 신호가 된다. **미감이 기능이다.**

**포지셔닝은 "소속사 없는 사람의 매니저".** 화려함이 아니라 **든든함**이 목표다.
번쩍이는 이펙트로 놀래키는 게 아니라, 잘 차려입은 매니저처럼 정돈돼 보여야 한다.

**구조는 고정, 색과 무드는 갈래.** 아래 §1~§5(타입·간격·모션·컴포넌트·금지)는 어느 방향을
고르든 바뀌지 않는다. §6의 팔레트만 시안별로 다르다. 그래야 시안을 비교할 때
"뼈대가 달라서 달라 보이는" 착시 없이 **무드만 비교**할 수 있다.

## 1. 타이포그래피

### 1.1 폰트 — 두 개까지

| 역할 | 폰트 | 이유 |
|---|---|---|
| 본문·UI | **Pretendard Variable** | 한글 웹폰트의 사실상 표준. 자간·굵기가 안정적 |
| 숫자·메타 | **동일 폰트 `tabular-nums`** | 별도 mono 폰트를 추가하지 않는다 |

- **CDN `@import` 금지.** 현재 `globals.css:1`이 jsdelivr에서 불러오는데, 렌더 차단이자 외부 의존이다. `next/font/local`로 self-host 한다.
- 굵기는 **400 / 600 / 800 셋만** 적재한다. 그 사이 굵기가 필요하면 크기로 해결한다.
- 영문 디스플레이 폰트를 섞고 싶으면 **히어로 한 곳에만**. 두 곳 이상 쓰면 시스템이 무너진다.

### 1.2 타입 스케일 — 의미 이름으로

역할이 없는 크기는 만들지 않는다. 여덟 단이면 충분하다.

| 토큰 | 크기 / 행간 | 자간 | 용도 |
|---|---|---|---|
| `display` | 56 / 1.06 | -0.03em | 히어로 H1 (모바일 40) |
| `title-1` | 38 / 1.15 | -0.022em | 섹션 H2 (모바일 30) |
| `title-2` | 24 / 1.25 | -0.015em | 카드 제목, H3 |
| `body-lg` | 17 / 1.65 | -0.005em | 히어로 서브, 리드 문단 |
| `body` | 15 / 1.7 | 0 | 본문 |
| `body-sm` | 13.5 / 1.6 | 0 | 보조 설명 |
| `label` | 12 / 1.4 | 0.02em | 폼 라벨, 배지 |
| `micro` | 10.5 / 1.3 | 0.16em | 대문자 눈썹 라벨, 메타 |

**규칙**
- 크기가 커질수록 자간은 **음수로**, 행간은 **좁게**. 작아질수록 반대.
- 헤딩은 `text-wrap: balance`, 설명 문단은 `text-wrap: pretty`.
- 본문 한 줄은 **한글 기준 40~45자**에서 끊는다(`max-w-[42ch]`). 넘어가면 읽는 속도가 떨어진다.
- 변하는 숫자(D-day·건수·금액)에는 **반드시 `tabular-nums`**. 없으면 숫자가 갱신될 때 폭이 흔들린다.
- 히어로 H1은 **줄바꿈을 손으로 지정**한다. 자동 줄바꿈에 맡기면 리듬이 깨진다.

## 2. 간격 — 4px 배수, 섹션은 크게 숨 쉬게

```
2 · 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128   (px)
```

| 자리 | 값 |
|---|---|
| 아이콘↔글자 | 8 |
| 카드 내부 패딩 | 20~24 |
| 카드 사이 | 12 (밀집 목록) / 24 (여유 그리드) |
| 블록 사이 | 48 |
| **섹션 상하** | **96 (모바일) / 128 (데스크톱)** |
| 컨테이너 최대폭 | 1152 (`max-w-6xl`) · 글 중심 섹션은 768 |

**섹션 여백을 아끼지 않는다.** 지금 랜딩이 답답해 보이는 가장 큰 원인이 여백 부족이다.
여백은 빈 공간이 아니라 "여기까지가 한 덩어리"라는 신호다.

## 3. 모션 — 스프링이 기본, CSS 트랜지션은 상태 변화에만

`apple-design` 원칙: **모션은 현재 화면 값에서 시작하고, 사용자의 속도를 상속하고,
언제든 잡아서 되돌릴 수 있어야 한다.**

### 3.1 값

| 상황 | 방식 | 값 |
|---|---|---|
| 진입 리빌(스크롤) | CSS transition | `900ms` `cubic-bezier(0.16, 1, 0.3, 1)` |
| 상태 변화(hover·색) | CSS transition | `200ms` `cubic-bezier(0.4, 0, 0.2, 1)` |
| 누름 피드백 | CSS transform | `scale(0.98)`, **pointer-down 즉시** |
| 제스처·드래그·시트 | **스프링** (Motion) | `stiffness 260` / `damping 30` / `mass 1` — 임계감쇠, **오버슈트 0** |
| 플릭·관성이 있는 것 | 스프링 | `stiffness 200` / `damping 26` — **오버슈트 최대 2%**, settle 400ms 이내 |

### 3.2 규칙

- **누르는 순간 반응한다.** `click`을 기다리지 않는다. 지연이 보이는 순간 직접성이 무너진다.
- **제스처가 있는 것에 CSS `transition`·`@keyframes`를 쓰지 않는다.** 중간에 잡아 되돌릴 수 없다.
- 진입 애니메이션은 **한 번만** 재생한다. 스크롤을 되감을 때 다시 뜨면 산만하다.
- `transform` · `opacity` · `filter` **만** 애니메이션한다. `top`/`left`/`width`/`height` 금지.
- `scroll` 이벤트 대신 **IntersectionObserver**.
- `prefers-reduced-motion: reduce` 이면 **전부 즉시 표시**. 예외 없다.
- 스태거는 **80ms** 고정. 카드 목록만 예외적으로 60ms.

**"스프링을 쓰되 바운스는 금지"가 모순처럼 보이는 지점 —** 스프링은 감쇠 값에 따라 튕길 수도,
안 튕길 수도 있다. 우리 기준은 이렇다.

| 항목 | 상한 |
|---|---|
| 오버슈트 | **2%** (플릭 계열만 허용, 나머지 0%) |
| settle time | **400ms** |
| scale 변화 | `0.96 ~ 1.04` 밖으로 나가지 않음 |
| translate 되돌아오는 양 | 8px 이하 |

이 상한을 넘으면 "탄성"이고, 넘지 않으면 "무게감"이다. 눈으로 판단하지 말고 값으로 판단한다.

## 4. 컴포넌트 규격

### 4.1 표면 — 이중 테두리(중첩) 구조

카드를 배경에 평평하게 놓지 않는다. 바깥 껍데기 + 안쪽 코어로 물리적 깊이를 만든다.

```
바깥: 미세한 배경 + 헤어라인 링 + padding 6~8px + radius R
안쪽: 실제 표면 + 안쪽 하이라이트(inset highlight) + radius (R − padding)
```

동심원이 맞아야 한다. 바깥 `1.4rem` / 패딩 `0.375rem` → 안쪽 `calc(1.4rem - 0.375rem)`.

### 4.2 라운드

범위로 두면 사람마다 다른 화면이 나온다. **고정값이다.**

| 요소 | 바깥 radius | 패딩 | 안쪽 radius |
|---|---|---|---|
| 버튼·배지·칩 | `9999px` | — | — |
| **공고 카드** | `22px` | `6px` | `16px` |
| **큰 컨테이너** | `30px` | `8px` | `22px` |
| 입력 | `12px` | — | — |

안쪽 radius = 바깥 − 패딩. 이 관계를 깨면 동심원이 틀어져 눈에 거슬린다.

`rounded-3xl` 이상은 **큰 컨테이너에만**. 작은 요소에 과한 라운드를 주면 장난감처럼 보인다.

### 4.3 버튼

- **1차 CTA는 화면당 하나.** 채움 배경은 그 하나만 갖는다.
- 화살표 아이콘은 **자체 원형 래퍼 안에** 넣고 버튼 오른쪽 안쪽 패딩에 딱 맞춘다. 글자 옆에 벌거벗고 붙이지 않는다.
- hover 시 아이콘만 대각선으로 살짝 이동 + 확대. 버튼 전체 색을 바꾸지 않는다.

### 4.4 아이콘

- **인라인 SVG, stroke 1.2~1.5**. 두꺼운 아이콘 세트 금지.
- 아이콘만으로 의미를 전달하지 않는다. 항상 글자와 함께.

### 4.5 그림자

- 어두운 배경에서는 **그림자 대신 헤어라인과 밝기 차이**로 깊이를 만든다.
- 밝은 배경에서만 그림자를 쓰되, **넓고 옅게**. `0 1px 2px` + `0 12px 32px -8px` 두 겹.
- **컬러 글로우 그림자 금지**(`shadow-indigo-300/30` 류).

## 5. 절대 금지 — 어기면 그 시안은 탈락

`20_design-language.md`의 AI-slop 목록을 계승하고 실측으로 보강했다.
현재 배포된 랜딩이 이 중 6개를 위반하고 있었다.

1. **그라데이션** — CSS `linear-gradient`/`radial-gradient`를 **배경·텍스트·버튼**에 쓰지 않는다. 특히 보라→핑크.
   *(단, 3D/WebGL 렌더 결과물의 조명·깊이 감쇠는 이 금지에 해당하지 않는다. 금지 대상은 "색면을 그라데이션으로 칠하는 미감"이지 물리 렌더가 아니다.)*
2. **이모지 아이콘** (`😩` `⏰` `📝`)
3. **컬러 글로우 섀도우**
4. **균일한 rounded 카드 3열 그리드** — 크기가 전부 같은 카드 세 장
5. **센터 정렬 히어로 풀세트** — 배지 + 큰 제목 + 부제 + CTA 2개 수직 나열
6. **라운드 넘버 가짜 통계** (`500+`, `10,000+`) — 숫자는 전부 DB 실측
7. **없는 고객사 로고 바** — 실사용자가 0명인 상태에서 신뢰를 위조하지 않는다
8. **같은 CTA 문구 반복** (`무료로 시작하기` ×4)
9. **스크롤 하이재킹** — 읽기를 방해하는 스크롤 가로채기
10. **바운스·탄성 모션** — 장난스러워 보인다

## 6. 팔레트 — 시안별 갈래 (여기만 바뀐다)

구조는 동일하고 **hue와 명도만** 다르다. 각 안은 중립 램프 1개 + 액센트 1개 + 상태색으로 구성한다.
`better-colors` 원칙: **한 색은 한 뜻.** 액센트는 "상호작용"에만 쓰고 정적 텍스트에 쓰지 않는다.

### 안 A — 스포트라이트 (다크 · 앰버)
무대 조명 은유. 오디션 = 무대에 서는 일.

```
bg        #121010   surface #1C1918   raised  #262220
text      #F5F1EA   muted   #9A9088   faint   #6B635A
accent    #F5C451   (스포트라이트 앰버 — 상호작용 전용)
danger    #E5533D   success #6FBF8B
hairline  rgba(245,241,234,0.10)
```

### 안 B — 웜 라이트 (밝음 · 절제)
정보 밀도가 높은 목록에 유리하다. 엔터 감성이 약한 건 **사진과 타이포로 보완**한다
(흑백 인물 사진 + 큰 헤드라인). 액센트가 행정 서비스처럼 보이지 않게 채도를 지킨다.

```
bg        #FAF8F5   surface #FFFFFF   raised  #F2EEE8
text      #17150F   muted   #5C554B   faint   #8B8378
accent    #B4551F
danger    #C0392B   success #2E7D4F
hairline  rgba(23,21,15,0.10)
```

**후보를 둘로 줄인 이유** — 시안은 선택지를 넓히려고 뽑는 게 아니라 **결정하려고** 뽑는다.
검토 과정에서 뺀 안:
- *하이컨트라스트(흑백)* — 무채색만으로 hover·focus·selected·disabled·danger를 구분해야 해서
  실제 UI 구현 난도가 가장 높다. "가장 절제된 안"이 아니라 "가장 어려운 안"이었다.
- *미드나이트(시안)* — 테크 느낌이 강해 아티스트 타깃과 어긋난다. 회의 시간만 잡아먹는다.

### 액센트 사용 상한 — 횟수가 아니라 면적으로

"화면당 2~3회"는 모호하다. **첫 화면 기준 액센트가 칠해진 면적이 3% 이하**여야 한다.
포함 대상: 1차 CTA 배경, 활성 필터 칩, focus ring, 링크 밑줄. 텍스트 색은 포함하지 않는다.
앰버(`#F5C451`)는 다크 배경에서 강해서, 이 상한을 넘으면 바로 "저가형 프리미엄"이 된다.

### 랜딩과 앱은 다른 모드를 쓸 수 있다

| 화면 | 기본 | 이유 |
|---|---|---|
| **랜딩** | 안 A(다크) 우선 검토 | 첫인상·엔터 감성 |
| **앱 내부**(공고 목록·상세·프로필) | **안 B(라이트)** | 마감일·조건·회사명을 계속 읽는 화면이다. 밝은 배경이 훨씬 읽기 쉽다 |

둘 다 같은 토큰 이름을 쓰고 값만 다르다. 랜딩→앱 전환 시 색이 바뀌는 건 의도된 것이고,
**전환 지점(로그인·공고 보기)에 뚜렷한 경계**를 둔다.

**측정 규칙:** 배포 전 모든 텍스트/배경 쌍의 대비를 **실제로 재고** 기록한다.
본문 4.5:1, 큰 글자 3:1 미만이면 그 조합은 쓰지 않는다. 눈대중 금지.
측정값은 `docs/renewal/24-contrast-audit.md`에 표로 남긴다.

## 7. 3D·이펙트 — **기본값이 아니다. 옵션이다.**

처음에는 3D 히어로 배경을 기본으로 두려 했으나 검토에서 뒤집었다. 근거:

1. **첫 화면의 주인공은 실제 공고다.** 배경 3D가 시각 우선순위를 가져가면
   "공고가 자산"이라는 전제와 정면으로 충돌한다.
2. **모바일에서 끌 거면 핵심 비주얼로 삼으면 안 된다.** 국내 오디션 지망생 트래픽은
   모바일 비중이 클 가능성이 높다. 모바일에서 정지 이미지로 대체되는 장치를
   첫인상의 핵심에 두는 건 앞뒤가 안 맞는다.
3. **포지셔닝이 "든든한 매니저"다.** 번쩍이는 3D는 포트폴리오 템플릿처럼 읽힌다.

### 7.1 그래서 이렇게 쓴다

| 자리 | 판단 |
|---|---|
| 히어로 **배경 레이어** | 🟡 **선택.** 채택하려면 §7.2 게이트를 **전부** 통과해야 한다 |
| 섹션 제목 등장 효과 | 🟡 페이지에 **하나만**. CSS로 되면 CSS로 |
| CTA 버튼 | ❌ 그라데이션 변형이 많아 금지 목록과 충돌 |
| 그 외 | ❌ |

### 7.2 채택 게이트 — 하나라도 못 넘으면 3D를 쓰지 않는다

| 항목 | 기준 |
|---|---|
| WebGL 번들 | **150KB(gzip) 이하** |
| 히어로 LCP | **2.5s 이하** (Moto G Power / 4G 시뮬레이션) |
| 3D 위 텍스트 대비 | **4.5:1 이상** — 못 넘으면 텍스트를 3D 밖으로 뺀다 |
| 모바일 폴백 | `viewport < 768px` **또는** `deviceMemory < 4` **또는** `prefers-reduced-motion` → 정지 이미지(WebP, 1회 렌더 캡처) |
| WebGL 실패 | `canvas.getContext('webgl2')`가 null이면 CSS 단색 배경으로 폴백. **검은 화면 금지** |
| 뷰포트 밖 | IntersectionObserver로 `pause`. 배터리·GPU를 계속 태우지 않는다 |
| 레이어 관계 | 3D는 `z-0` 배경. 공고 카드·제목·CTA는 그 위 `z-10`. **콘텐츠를 3D 안에 넣지 않는다** |
| 서버 렌더 | 3D 유무와 무관하게 제목·본문·공고는 **전부 서버 HTML**로 존재한다. 검색·AI 색인이 목적이므로 타협하지 않는다 |

### 7.3 외부 컴포넌트를 쓸 때

ThreeUI(무료 164종)는 **참고 소스**이지 의존성이 아니다.
- `npm install`로 통째로 붙이지 않는다. **필요한 장면 하나를 우리 코드로 옮겨 적는다.**
  패키지 종속이 되면 디자인 시스템이 아니라 샘플 모음이 된다.
- 라이선스 확인: 커뮤니티판 코드·이미지는 MIT, 폰트는 SIL OFL 1.1, 외부 미리보기는 별도.
- 옮겨 적은 뒤 §7.2 게이트를 다시 잰다.

## 8. 콘텐츠 원칙 — 디자인과 한 몸

### 8.1 첫 화면 숫자는 두 개까지

```
✅  매일 100건 넘게 새로 올라옵니다      ← 살아있음의 증거. 재방문 이유
✅  지금 4,500건이 열려 있습니다          ← 재고

❌  활성 4,537 / 원클릭 362 로 쪼개기     ← 팩트지만 나눌 이유가 없다
❌  격리한 위험 공고 16건                 ← 0.35%라 임팩트가 없고, 불안을 먼저 심는다
                                          신뢰는 숫자가 아니라 프로세스로 말한다
```

### 8.2 첫 화면에 실제 공고가 보여야 한다

재고가 최대 자산인데 안 보이면 없는 것과 같다. 히어로에 **오늘 올라온 공고 4건**을 실제로 렌더한다.

### 8.3 가입 게이트는 한 곳

**보는 건 가입 없이. 대신 지원할 때만 가입.** 없는 벽을 광고하지 않는다.

### 8.4 신뢰는 프로세스로

`"참가비를 요구하는 공고는 자동으로 걸러냅니다"` 가 `"16건 격리"` 보다 강하다.
출처 표기 · 원문 링크 · 위험 신호 점검 · 신고 즉시 중지 — 하는 일을 그대로 쓴다.

## 9. 접근성 (타협 없음)

- 대비: 본문 **4.5:1**, 큰 글자·UI **3:1** 이상. 측정값을 기록한다.
- 포커스 링을 지우지 않는다. `:focus-visible`로 명확하게.
- 터치 타깃 **44×44px** 이상.
- 색만으로 의미를 전달하지 않는다. 마감 임박은 색 + 글자(`D-2`) 둘 다.
- 모든 이미지에 `alt`. 장식용은 `alt=""` + `aria-hidden`.
- `prefers-reduced-motion` 존중.

---

## 10. 성능 (SEO와 직결되므로 미감보다 우선하는 항목)

- **본문은 전부 서버 렌더.** 인터랙션만 클라이언트 아일랜드로 분리한다.
- GSAP·Lenis 같은 스크롤 라이브러리를 **기본으로 쓰지 않는다.** 시네마틱한 인상은 타이포·명암·타이밍으로 만든다. 꼭 필요한 한 곳에만 검토한다.
- 폰트 self-host + `font-display: swap`.
- `backdrop-blur`는 **고정·스티키 요소에만**. 스크롤 콘텐츠에 걸면 GPU를 계속 태운다.
- 노이즈·그레인은 **고정 `pointer-events-none` 레이어**로.
- 이미지는 `next/image` + 적절한 `sizes`. 히어로 이미지에 `priority`.

## 11. 시안 평가 — 통과/탈락 + 점수

"그냥 이게 나아 보인다"를 근거 있는 선택으로 바꾸기 위한 장치다.
**미감은 중요하지만 이해를 이기지 못한다.** 예쁜데 뭘 하는지 모르는 페이지는 실패다.

### 11.1 통과/탈락 (하나라도 실패하면 그 시안은 탈락)

| # | 항목 | 판정 방법 |
|---|---|---|
| G1 | **3초 안에 무슨 서비스인지 아는가** | 처음 보는 사람에게 3초 노출 후 한 문장으로 설명시킨다 |
| G2 | **첫 화면에 실제 공고가 보이는가** | 스크롤 없이 공고 제목·마감이 보이면 통과 |
| G3 | **§5 금지 10개를 하나도 안 어겼는가** | 코드/시안 검사 |
| G4 | **360 / 390 / 430 / 768px에서 안 무너지는가** | 네 폭 전부 실측. 가로 스크롤·겹침·잘림 없음 |
| G5 | **대비 4.5:1(본문) / 3:1(큰 글자)** | 측정값 기록 |

### 11.2 점수 (통과한 시안끼리 비교, 100점)

| 항목 | 배점 | 판정 |
|---|---|---|
| **타깃 인상** | **35** | 지망생 5명에게 3초 노출 후 "신뢰감 / 전문성 / 지원 의향" 5점 척도. **내부 취향으로 판단하지 않는다** |
| 정보 위계 | 20 | 제목 → 부제 → 근거 → 행동 순으로 눈이 흐르는가 |
| 여백·리듬 | 15 | §2 간격 스케일을 지켰는가 |
| 액센트 절제 | 10 | 첫 화면 액센트 면적 3% 이하 |
| 모션 품질 | 10 | §3 상한 준수, 산만하지 않은가 |
| 성능 | 10 | LCP·CLS·번들. 3D를 썼다면 §7.2 게이트 |

**타깃 인상이 35점인 이유** — 우리가 답을 모르는 유일한 항목이라서다.
나머지는 문서를 보면 채점할 수 있지만, "촌스러운가"는 타깃만 답할 수 있다.
지망생 5명은 인스타 DM·커뮤니티로 모으면 하루면 된다.

### 11.3 채점하지 않는 것

- "내가 보기에 예쁘다" — 근거가 아니다
- "요즘 트렌드다" — 6개월 뒤 촌스러워진다
- "경쟁사도 이렇게 한다" — 그 회사도 틀렸을 수 있다
