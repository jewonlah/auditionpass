# 개인 자료 보관함 — 2026-09-13

사용자가 기존 Supabase CLI 연결을 재사용해 자료 보관함을 진행하도록 요청했다. 별도 서비스 가입이나 사용자 측 폴더 생성은 필요하지 않다.

## 구현

- `/portfolio/materials`: 기존 포트폴리오에서 진입하는 비공개 개인 자료 보관함. 파일 업로드, 목록 재조회, 종류 필터, 다운로드, 확인 후 삭제.
- 파일당 3MiB, 계정당 100개. JPG/PNG/WebP/PDF/MP4/WebM/MP3/WAV 허용. 파일 크기·이름·MIME·기본 시그니처를 서버에서 확인한다. 정밀 미디어 분석이나 악성코드 검사는 아니다.
- `materials` 테이블과 비공개 Storage 버킷. 사용자에게는 자기 목록 SELECT만 허용하고 변경·파일 접근은 인증된 API에서 수행한다. 기존의 넓은 Storage 정책에도 노출되지 않도록 제한적 정책을 추가했다.
- 업로드 완료 후 목록에 등록해 다른 탭에서 진행 중 파일을 삭제하지 못하게 한다. DB 등록 실패 시 파일 정리를 시도하고, 정리 실패는 서버 로그에 남긴다. 계정별 DB 잠금으로 100개 제한을 검사한다.
- 다운로드는 소유권 확인 후 60초짜리 다운로드 링크를 발급한다. 링크는 유효 시간 내 소지자가 접근할 수 있다. 계정 탈퇴 시 기존 파일 작업 잠금을 사용하고 보관함 파일부터 제거한다.
- 업로드 완료 여부가 불명확하면 기존 파일 수명주기 규칙에 따라 작업 토큰을 남긴다. 이런 장애는 자동 만료하지 않으며 운영 확인이 필요하다.
- 보관함 파일은 현재 제출 PDF·지원 메일에 자동 첨부하지 않는다. 화면에 명시했다. 제출 선택 연결, 큰 파일 직접 업로드, 기존 자료 가져오기는 후속 범위다.
