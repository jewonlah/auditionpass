# 리뉴얼 전략 결정 브리프 (2026-07-15)

> Phase 1 진단(01~03 보고서) 종합 후 확정한 전략 결정. Phase 2 기획서/PRD/IA 작성 시 이 브리프를 상위 기준으로 삼는다.
> 근거: `01_service-research.md`, `02_ux-audit.md`, `03_design-copy-seo-audit.md`

## D1. 포지셔닝 — "기능"이 아니라 "커버리지 + 신뢰 + 전달물 품질"
- 원클릭 지원 소구는 쇼스타·유디션과 겹침. 차별화 축을 다음 3개로 확정:
  1. **커버리지**: 국내 유일급 크로스사이트 수집(10+ 소스) + Google Jobs SEO
  2. **신뢰**: 검증 배지("안심 오디션"), 출처 투명성
  3. **전달물 품질**: 컴프카드 PDF 자동 생성 — 업계 표준 포맷으로 지원 메일의 격을 올림
- 브랜드 메시지 축: 기능("한 곳에서") → 열망("당신의 다음 무대") + 선배 톤

## D2. 수익모델 재설계 — 핵심 행동 벌점화 폐지
- **지원 횟수 제한(일 1회) 폐지 또는 대폭 완화**. 지원은 핵심 가치 행동이므로 무료 개방.
- 과금 대상 전환(Backstage식): ① 프로필 상단 노출/부스트 ② 마감 임박·맞춤 알림 ③ 컴프카드 프리미엄 템플릿 ④ 지원 열람 확인 등 "성공 확률"에 과금.
- 빈 `/pricing` 스텁·가짜 광고 시뮬레이션은 리뉴얼에서 제거(데드엔드 CTA 금지).

## D3. 양면 시장 씨앗 — CD(캐스팅 디렉터) 측 진입로
- 지원 메일에 "지원자 보드" 웹뷰 링크 포함 → CD가 클릭하면 지원자 목록/컴프카드를 웹에서 열람 → CD 무료 계정 전환 유도.
- 스팸 처리 리스크(정형 대량 메일)의 방어책이자 수요 측 확보의 시작점. MVP는 읽기 전용 보드.

- **개정(2026-08-22, 사용자 결정)**: 인스타·스레드·X는 **운영자 계정의 브라우저 세션**으로 화이트리스트 계정·키워드 검색을 소량 수집한다(요약+출처 링크, 사람 속도, 밴 리스크 운영자 인지, 관리형 API는 백업). 네이버 카페·블로그·웹문서(공식 API), 카카오 카페, 고용24, 공공·기획사·극단 공식 페이지도 소스. **경쟁 애그리게이터는 저장하지 않고 원출처 역추적에만 사용**(잡코리아 v 사람인). 신규 출처는 검수 큐(`review_status`)·출처 신뢰(`trusted_sources`)로 게재 통제. 상세: `32_sourcing-all-options.md`, 플랜 `34`.

- `apply_email` 보유율(원클릭 적용률)을 상시 측정 지표로 승격.

## D5. IA — 모바일 앱형 5탭 + 여정 단절 제거
- 탭: **홈 / 탐색(오디션) / 지원 / 커뮤니티 / MY** (지원을 1급 탭으로 승격).
- **returnTo 시스템 전면 도입**: 로그인/프로필/게이트 어디서든 원래 맥락으로 복귀. (현재 최대 이탈점: 프로필 저장 후 랜딩 추방 버그)
- 프로필 게이트: 에러+리다이렉트 → **인라인 바텀시트**로 전환. 지원 의도 최고점에서 이탈 금지.
- 온보딩: 가입 직후 3스텝(스킵 가능) — 분야 선택 → 미니 프로필 → 첫 추천.
- 프로필 폼 15필드 → 단계 분할: 지원에 필요한 최소(미니 프로필) vs 완성(컴프카드용).
- 로그인 상태에서 `/` = 앱 홈(랜딩은 비로그인 전용), 로고 클릭은 앱 홈으로.

## D6. 디자인 방향 — A+C 하이브리드 (03 보고서 추천안 채택)
- **랜딩/마케팅 표면**: 「캐스팅 콜 시트」 에디토리얼 — 인쇄물 콜시트의 타이포그래피 규율, 실제 공고 데이터를 히어로 재료로.
- **앱 내부**: 「콜시트 유틸리티」 미니멀 — 정보 밀도·스캔 속도 우선, 균일 카드 반복 폐지, 스켈레톤 로딩.
- 브랜드 인디고(#6366F1) 유지하되 **그라데이션·글로우·이모지 아이콘 전면 금지**(AI-slop 18건 근거). 인디고는 액션·포커스에만 절제 사용.
- 모션: 페이지 전환·리스트 스태거·바텀시트 스프링 등 앱형 마이크로 인터랙션. `prefers-reduced-motion` 대응 필수.
- 폰트: Pretendard 유지, CDN @import → self-host/next-font로 교체.
