### 1-E. 범용 읽기 엔진 (모든 채널의 공통 후단)

- **LLM 추출기** (`utils/llm_extract.py`, Haiku): 페이지 텍스트 → `{title, company, deadline, apply_email, requirements, category}` JSON → `AuditionData`. 사이트 추가 = 목록 URL 1줄, 셀렉터 0줄. 페이지당 ≈₩1~2. **전제: Anthropic 크레딧(§0-2)**.
- 렌더링 보조: Playwright(이미 의존성) / Jina Reader·Firecrawl(외부 서비스, JS 렌더·본문 추출 대행, 무료 티어) — 자체 Playwright로 충분하면 불필요.
- 디스커버리: 네이버 웹문서·카카오·구글 Programmable Search(일 100회 무료)로 "오디션 공고 지원 이메일" 류 검색 → 새 도메인 발견 → 화이트리스트 제안.

## 3. 법적 기준 — 한국 판례로 정한 우리 규칙

- **야놀자 v 여기어때(대법원 2022)**: 누구나 접근 가능하고 별도 보호조치 없는 정보를 크롤링한 것만으로는 정보통신망 침입이 아님 → **공개 페이지 수집 자체는 형사 리스크 낮음**.
- **잡코리아 v 사람인(서울고법 2017, 합의 120억)**: 경쟁사 채용정보를 **통째로 복제해 자기 영업에 사용**한 것은 데이터베이스제작자 권리 침해 → **경쟁 애그리게이터의 DB를 대량 복제해 재게시하면 안 됨**.
- 따라서 우리 규칙(00 D4 재확인):
  1. **요약 + 출처 배지 + 원문 링크** 원칙 유지. 본문 전문 재게시 금지(현재 description은 요약/300자 정제).
  2. 경쟁 애그리게이터(캐스팅찾고·Audee·쇼스타·플필 등)는 **링크 인덱스 수준**으로만, 또는 제외. 1차 출처(제작사·극단·기획사·학교·커뮤니티 원글)를 우선.
  3. 로그인 벽·유료 벽 뒤 정보는 수집하지 않음(멤버공개 카페 401은 존중).
  4. robots.txt의 **명시 차단 UA**는 사칭하지 않음(우리는 일반 브라우저 UA, 속도 제한 준수). 데이터센터 IP 차단은 자택 러너로 "정상 이용자와 같은 위치"에서 접근 — 이건 우회가 아니라 실행 위치 선택이지만, 사이트가 명시적으로 수집 금지 의사를 밝히면 중단.
  5. 비공식 엔드포인트(카페 본문 JSON)는 보강 용도·저속·차단 시 즉시 중단.
